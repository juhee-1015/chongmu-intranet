브라우저가 달라도 데이터를 유지하는 방법을 선택하세요

📤 내보내기 (현재 브라우저 → 파일)
지금 이 브라우저에 저장된 모든 데이터(거래처, 상품권, 공지, 링크, 업무체크)를 하나의 JSON 파일로 내보냅니다.
📥 가져오기 (파일 → 현재 브라우저)
내보낸 JSON 파일을 선택하면 현재 브라우저에 데이터가 복원됩니다.
⚠️ 기존 데이터는 덮어씌워집니다.
연결 안됨
1단계. jsonbin.io 무료 가입 → API Keys 메뉴에서 Master Key 복사
2단계. 아래에 붙여넣기 후 "연결 & 저장" 클릭
3단계. 생성된 Bin URL을 팀원에게 공유
JSONBin 연결 후 아래 URL을 팀원에게 공유하세요.
팀원은 이 URL을 "JSONBin" 탭의 Bin URL에 입력하면 데이터를 볼 수 있습니다.
⚠️ Master Key 없이는 읽기 전용으로만 사용됩니다.
💡 현재는 같은 PC에서 백업/복원으로도 충분합니다. 팀 전체 공유는 나중에 GitHub → Vercel 배포 후 해결하는 게 가장 깔끔합니다.
