📤 내보내기 (현재 브라우저 → 파일)
지금 이 브라우저에 저장된 모든 데이터(거래처, 상품권, 공지, 링크, 업무체크)를 하나의 JSON 파일로 내보냅니다.
📥 가져오기 (파일 → 현재 브라우저)
내보낸 JSON 파일을 선택하면 현재 브라우저에 데이터가 복원됩니다.
⚠️ 기존 데이터는 덮어씌워집니다.

1단계. GitHub → 우측 상단 프로필 → Settings → Developer settings → Personal access tokens → Tokens (classic)
2단계. Generate new token → Note에 이름 입력 → repo 체크 → Generate
3단계. 발급된 토큰 복사 후 아래에 입력
