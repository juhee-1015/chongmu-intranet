☁️ 데이터 동기화 & 백업

💡 총무 대백과와 동일한 GitHub 저장소·토큰을 공유합니다. 한 번 설정하면 양쪽 모두 사용 가능.

📤 내보내기 (현재 브라우저 → 파일)
현재 예산관리 데이터(실적, 조정, 이관 이력)를 JSON 파일로 저장합니다.
📥 가져오기 (파일 → 현재 브라우저)
저장해둔 JSON 파일을 선택하면 데이터가 복원됩니다.
⚠️ 기존 데이터는 덮어씌워집니다.
연결 안됨
저장할 때마다 이름이 커밋 메시지에 기록됩니다. 팀원들도 각자 이름 입력 후 저장하세요.
1단계. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2단계. Generate new token → repo 체크 → Generate
3단계. 발급된 토큰 복사 후 아래에 입력 (총무 대백과와 동일한 토큰 사용 가능)
💡 총무 대백과(data.json)와 예산관리(budget_data.json)는 같은 저장소의 서로 다른 파일에 저장됩니다.
GitHub에 저장된 버전 목록입니다. 원하는 시점으로 복원할 수 있습니다.
"목록 새로고침"을 눌러 버전 히스토리를 불러오세요.
GitHub 동기화 탭에서 토큰·저장소를 먼저 설정해야 합니다.
